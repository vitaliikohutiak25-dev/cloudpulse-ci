# Changelog

Усі помітні зміни в проєкті CloudPulse документуються в цьому файлі відповідно до принципів [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) та стандарту [Semantic Versioning (SemVer)](https://semver.org/).

## [1.2.0] - 2026-11-14
### Додано
- Автоматизований CI/CD-пайплайн у GitHub Actions (`.github/workflows/ci.yml`).
- Кросверсійне тестування за допомогою матриці оточень (Python 3.10 та 3.11).
- Генерація та публікація релізного ZIP-артефакту (`cloudpulse-app-artifact`).
- Динамічний статус-бейдж у документації README.

## [1.1.0] - 2026-11-14
### Змінено
- Оновлено бібліотеку Flask до безпечної версії `3.1.3` (усунення вразливості PYSEC-2026-2151).
- Проведено повний рефакторинг коду за результатами Code Review та Pylint (рейтинг підвищено до 9.29/10).
- Змінні середовища приведені до стандарту констант `UPPER_CASE`.
### Додано
- Автоматизовані модульні тести на базі Pytest (`tests/test_app.py`).
- Документацію docstrings (PEP 257) для модулів та методів API.

## [1.0.0] - 2026-11-14
### Додано
- Базовий веб-сервіс телеметрії на Flask (`app/main.py`).
- Оптимізований `Dockerfile` на базі легкого образу `python:3.11-slim`.
- Маніфест `docker-compose.yml` для об'єднання Flask із кешем Redis у спільній мережі `pulse_net`.
