v1.2.0 • MVP

CloudPulse Telemetry API

Контейнеризований мікросервіс моніторингу вузлів (Python/Flask + Redis) із налаштованим CI/CD, модульними тестами та аудитом безпеки.

Репозиторій на GitHub → Переглянути CI/CD Actions Аудит безпеки (OWASP)

Архітектура та Docker

Двосервісний стек у віртуальній мережі pulse_net: Flask API на порту 8080 та кеш Redis 7.2 на 6379. Оптимізований multi-stage Dockerfile на базі python:3.11-slim.

Якість та Безпека

Проведено Code Review: рейтинг Pylint зріс з 6.67 до 9.29/10. Оновлено Flask до 3.1.3 після виявлення PYSEC-2026-2151 через pip-audit. SAST-перевірка Bandit зафіксувала B104.

CI/CD та Тестування

GitHub Actions запускає лінтер, компіляцію та 2 тести pytest на матриці Python 3.10 та 3.11 при кожному push із пакуванням артефакту.

Відомі технічні обмеження (Технічний борг)

Поточна версія є навчальним MVP: використовується dev-сервер Flask без Gunicorn, порт Redis 6379 доступний без пароля в локальному compose, а ендпоінт / не вимагає JWT-авторизації. Детальний план усунення зафіксовано у security-debt.md.
